# 场景文件与生命周期

## 文件

场景文件是 UTF-8 的 `.scn.ron`，外层为 `(version: 1, scene: ...)`，payload 由 Bevy 0.18 DynamicScene 反射序列化。该封装不等同于 Bevy 默认 loader 直接读取的原生场景文件。

保存仅提取 SceneOwned 实体及持久组件白名单。文件不包含任意 Resource、GPU 状态、加载错误、选择状态或编辑器窗口。SceneMetadata 保存场景名称和活动相机引用，Environment 位于该元数据根实体。

实体标识由后端在加载时重映射；parent 和活动相机引用必须属于当前文件。children 和 WorldTransform 不保存。资产路径相对于 assets 根目录，与场景文件所在目录无关。

Vec3 使用 xyz 字段；四元数使用 cgmath 的命名结构 `s`（标量 w）与 `v`（xyz），不使用依赖数组顺序的位置编码。FOV 为度、旋转行为速度为弧度/秒，颜色为线性 RGBA。

## 校验范围

加载拒绝未知版本/类型、白名单外组件、重复实体、场景外引用、父子环、无效有限值和非法资源路径。注册了 Reflect 不自动获得持久化权限。

首版要求一个活动场景、一个根层活动相机、一个方向光和一个环境；点光源最多 128 个。活动相机具有有效 RenderTargetConfig 和 CSM，级联 1..=8，纹理尺寸受设备限制，阴影区间有效。

缩放为正值；有子节点的父变换要求均匀缩放，叶节点允许非均匀缩放。TRS 不表达剪切。场景文件用于仓库内功能测试，不保证组件路径/字段重命名及 Bevy 大版本间自动兼容。

## 打开与替换

启动、Open、Reload、面板双击共用控制器。默认启动文件是 scenes/minimal.scn.ron；命令行 `--scene` 接受根相对路径。

打开先解析并恢复候选 CPU World、校验引用和参数、准备独立资产作用域和相机/环境 GPU 结果，成功后排他提交。可恢复失败保留旧场景、当前路径和未保存修改；GPU 致命错误不承诺事务回滚。

切换不销毁窗口、Device 或公共管线。成功后清理旧选择、属性窗口和旧实体，更新环境纹理/SH，按场景 epoch 丢弃旧拾取读回，释放旧场景缓存。旧 egui viewport 纹理注册在当帧 UI 绘制后释放。

首版同步加载，可能短暂停顿；不进行目录预加载、后台加载、文件监听或热重载。

## 保存与修改保护

Save 更新当前文件；Save As 使用 assets 根内既有目录，新增文件要求 `.scn.ron` 后缀，覆盖另存目标需要确认。编码完整内容后写同目录临时文件、同步并替换，失败不截断原文件。

使用持久快照与保存基线比较实际修改；仅查看属性、更新 GPU、派生矩阵或编辑器布局不标脏。行为系统实际改变的局部 Transform 会保存，不提供独立 Play World。

打开其他内容时，未保存场景必须选择 Save and Open / Discard and Open / Cancel。保存失败或取消路径对话框不继续打开。错误在 UI 中可见。

## 复现工具

`cargo run --example generate_scenes` 生成最小场景与演示场景；演示场景依赖仓库模型，最小场景只使用程序化平面和应用默认环境。

`cargo run --example scene_smoke` 使用真实 GPU/窗口和场景控制器检查切换、未保存保护、磁盘保存重载及候选资产失败时旧场景保留。该工具不替代原生鼠标/键盘交互验收。
