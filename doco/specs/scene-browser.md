# 场景浏览面板

## 布局与入口

默认 Dock 布局在中央 viewport 下方显示 Content Browser 面板；左右 Control Panel 和 CSM Preview 不随之上下分割。保持底部停靠，不做快捷键抽屉。首帧依据实际可用高度为默认卡片预留空间；高度可调整，Reset Layout 恢复默认布局。

面板采用 UE Content Browser 式局部深灰主题：上方紧凑导航/搜索工具栏，左侧 Sources 目录树，右侧自适应卡片网格，底部 View 与状态栏。该样式不修改其他面板的全局主题。

File 菜单提供 Open、Save、Save As、Reload。浏览面板只发送统一场景请求，不自行解析文件、上传 GPU 资源或清空 World。

## 目录展示

初始目录为 AssetRoot（默认 assets）。右侧卡片只显示当前目录的普通文件夹和大小写不敏感的 `.scn.ron` 普通文件；空文件夹也显示。左侧树只显示文件夹，按需加载展开分支，不递归预扫整个资产根。

不显示普通 RON、BSN、模型、图片、点开头的隐藏条目和临时保存文件，不跟随符号链接或目录联接。目录排在文件前，各组按名称稳定排序；文件操作保留真实 PathBuf，不从显示字符串反推路径。

提供面包屑、上级、根目录和 Refresh；不能导航到根目录之外。卡片使用不依赖字体的矢量文件夹/场景类型图标；场景标题省略 `.scn.ron` 后缀，hover 显示完整根相对路径。首版没有其他资产种类、真实缩略图、拖放、导入及文件重命名/删除操作。

## 搜索与视图

搜索仅在当前目录中按名称做不区分大小写的内存过滤，不递归、不解析场景；不影响目录树。X 清空搜索，导航后自动清空。无匹配项与空目录使用不同提示。

View 菜单调整卡片大小并切换 Sources 显隐；工具栏也可切换 Sources。树与网格分别滚动；窄面板自动隐藏树，卡片按可用宽度换列，长名称截断并提供完整路径提示。卡片网格只构建可见行，目录缓存不会因绘制而逐帧重读。

## 操作与状态

卡片单击选择条目，双击文件夹进入目录，双击场景提交一次 Open。树节点单击导航，箭头只展开/折叠；导航后展开目标祖先。目录导航、搜索、视图尺寸和选择不改变当前场景或未保存状态。

当前场景卡片有独立 OPEN 标记，不把选择误认为已打开。底部显示筛选后的条目数、当前场景路径和未保存标记；hover 当前场景状态可查看操作结果与缓存统计。错误在工具栏下显示，长消息可 hover 读取。

未保存修改的处理遵循场景控制器的保存/放弃/取消规则。请求、确认或异步加载过程中禁止重复激活场景文件，File 场景操作菜单不可用；目录树、文件夹卡片、搜索、刷新和选择仍可操作。加载时显示阶段、目标场景和带 tooltip 的取消按钮，GPU 阶段显示网格/纹理/环境源图的已上传字节比例，不将其解释为总耗时比例。失败信息保留在工具栏。

首次显示、进入目录、展开未缓存的树节点、手动刷新及成功保存后更新相应目录缓存。Refresh/保存通知同时失效树与网格缓存；不逐帧递归扫描或监听文件系统。外部新增/删除需要刷新后可见。激活条目前重新检查路径和类型。

空目录显示空状态；目录不可读、文件被删除或变为链接时显示错误。当前子目录被删除后刷新回到根目录；根目录不可读时保留错误及重试入口。

## 输入边界

浏览面板的点击和滚动不触发 viewport 拾取。相机控制在 UI 确定本帧 viewport 输入归属之后执行；文本输入、场景确认对话框和异步加载会阻止相机控制。Escape 保留光标捕获/释放切换。

Viewport 目标尺寸和拾取坐标依据实际图像区域，不包含浏览面板；固定 Texture 目标不随面板大小改写其配置。浏览目录、搜索词、树展开状态、卡片大小、面板尺寸和选中条目均不保存进场景。
