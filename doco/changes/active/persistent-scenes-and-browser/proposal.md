# 持久化场景、GPU 资产引用与场景浏览面板

## Purpose

当前测试场景由 [src/lib.rs](../../../../src/lib.rs) 硬编码创建。模型路径没有作为实体数据保留，`PbrMaterial` 包含已上传纹理，模型加载与 GPU 上传耦合，编辑器修改也没有场景保存入口。同一模型的多个实例会分别上传网格。

本变更将实体数据划分为序列化组件和运行时组件：前者记录用户配置、资产来源与实体关系，后者根据前者、源文件和运行环境生成。GPU 资产集中缓存，实体使用运行时索引访问；磁盘文件只保存相对 [assets/](../../../../assets/) 的资源引用，不保存 GPU 对象或缓存索引。

同时在 viewport 下方增加场景浏览面板。用户可以浏览资产根目录中的文件夹，双击场景文件打开场景，不再通过修改 Rust 代码切换测试内容。

## Scope and acceptance

### 交付范围

- 分离模型的 CPU 解析与 GPU 上传，支持模型子资源引用、场景内资产共享以及独立的实体变换数据。
- 保留可序列化的 Transform、模型来源、材质覆盖、相机、渲染目标配置、灯光、CSM、环境与测试行为参数；GPU、派生变换、选择和编辑器窗口属于运行时状态。
- 建立新增、修改、移除、失败重试对应的运行时准备流程。配置不因准备完成而被删除。
- 实现场景保存、另存为、加载和替换；移除旧场景时保留窗口、设备、公共管线和编辑器。可恢复的加载失败不破坏当前场景。
- 首版保持 Bevy 0.18，采用 `bevy_scene::DynamicScene` 的反射序列化能力，场景扩展名固定为 `.scn.ron`。未来升级时可在序列化适配层迁移至 `bevy_world_serialization`，本变更不以升级为前置条件。
- 增加默认位于 viewport 下方、可调整高度的场景浏览面板。根目录为项目 assets 目录，首版只显示普通文件夹和 `.scn.ron` 场景文件；提供进入目录、返回上级、根目录导航和刷新。空文件夹仍显示，其他资产文件暂不显示。经用户补充确认，采用 UE Content Browser 式紧凑深灰工具栏、左侧目录树与右侧卡片网格；固定于底部，不做快捷键抽屉。支持当前目录名称搜索和图标尺寸调整，使用类型图标而非真实缩略图。
- 双击场景文件向统一场景控制器提交打开请求；单击只选择。面板提供打开结果、错误与当前场景信息。存在未保存修改时先提供保存、放弃、取消选择。
- 将当前硬编码演示场景迁移为文件，并提供不依赖外部模型的最小可重建场景。

### 验收标准

1. 保存、关闭并重新打开场景后，物体关系、局部变换、材质覆盖、相机、灯光与环境配置保持一致；运行时 GPU 数据由系统重新生成。
2. 多个实体引用同一网格时只解析和上传一份共享网格，各自移动不影响其他实体；复制实体不复制或误共享实例 GPU 状态。
3. 修改模型或纹理引用、移除来源组件、删除实体均能更新或清理对应运行时数据。缺失资产可诊断、可重试，不导致每帧重复加载或保存时丢失来源。
4. 场景文件不包含 GPU 对象、运行时 Handle、选择状态或编辑器窗口；加载时不接受未列入白名单的组件和资源。
5. 打开编辑器后，viewport 下方可见场景浏览面板；嵌套文件夹可导航，普通 RON、模型和图片不作为场景显示，双击有效场景文件能替换当前场景。
6. 浏览面板的点击、滚动、双击不触发 viewport 拾取或相机控制；调整面板大小后，渲染目标尺寸和拾取坐标只使用实际 viewport 图像区域。
7. 文件损坏、目录不可读、场景或资产被外部删除时显示错误而不崩溃；打开失败保留旧场景，取消切换保留未保存修改。
8. 切换场景后不遗留旧实体、旧环境 SH、拾取结果或属性窗口目标，旧场景资产可释放；公共渲染资源继续可用。

### 非目标

本变更不实现 BSN 文本读写、完整 glTF node/动画导入、Prefab 继承、跨场景资产引用、任意组件自动存档、通用脚本系统、后台异步加载、文件监听热重载、缩略图、资产拖放、文件重命名/删除、资源导入器 UI、全项目数学库迁移或 Bevy 版本升级。

场景浏览面板保留按条目类型扩展的边界，但首版不展示其他资产，也不预建通用资产编辑框架。场景资源先按场景作用域缓存，不实现跨场景 LRU。

### 预期契约变化

- 创建、编辑和加载实体统一写入序列化组件，由准备系统生成运行时结果；编辑器不再直接修改独立的派生材质数据。
- 保存单位是属于当前场景的实体及组件白名单，而非整个 World。
- 持久资源引用使用项目资产根目录下的路径和子资源选择器，运行时索引不具备跨进程身份。
- 场景文件用于仓库内功能测试；包含格式版本，但不承诺任意 Rust 类型重命名和 Bevy 大版本之间自动兼容。
- 场景浏览面板与保存功能共用路径判定、场景文件识别和打开入口，不另建一套加载逻辑。
