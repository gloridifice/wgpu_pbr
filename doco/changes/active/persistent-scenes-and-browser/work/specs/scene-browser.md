# Viewport 下方场景浏览面板目标契约

## Scope and current contracts

新增场景浏览面板，读取资产目录并打开场景。变更创建时的 [src/editor/gui/mod.rs](../../../../../../src/editor/gui/mod.rs) 只有 viewport、Control Panel 和 CSM Preview，没有文件浏览能力。本文是变更目标，不是现状描述。

面板依赖 [scene-persistence.md](scene-persistence.md) 的统一打开/保存契约。未来可扩展其他资产类别，但首版只显示文件夹和场景文件，不实现缩略图、拖放、导入或文件管理。

## Requirements

### SB-1 布局

默认布局中，场景浏览面板位于中央 viewport 正下方，与 viewport 上下分割，左右现有面板保持独立。面板可调整高度，Reset Layout 恢复该布局。面板不能覆盖 viewport 图像，缩放窗口后仍可访问。

用户补充确认采用 UE Content Browser 风格：紧凑深灰工具栏、左侧目录树、右侧自适应卡片网格和底部状态/图标大小控制。保持底部 Dock，不实现快捷键抽屉；局部样式不改变其他编辑器面板。矢量类型图标区分文件夹和场景，不生成真实缩略图。

### SB-2 文件展示

初始目录为统一的 [assets/](../../../../../../assets/) 根目录。列出当前目录的普通文件夹及文件名以 `.scn.ron` 结尾的普通文件；扩展名识别不区分 ASCII 大小写。显示空文件夹，不以“是否含场景”决定目录可见性。

不显示普通 `.ron`、`.bsn`、`.gltf`、`.glb`、图片及其他文件。隐藏以点开头的条目（包含 `.cache`）和临时保存文件，不跟随链接或目录联接。目录排在文件前，各组按名称稳定排序。

显示当前相对路径/面包屑，提供返回上级、返回根目录和 Refresh；根目录不能向上导航。右侧卡片双击文件夹进入目录，单击只选择条目；左侧树只显示文件夹，单击节点即可导航，箭头仅展开/折叠。导航后展开目标祖先，树和卡片区分别滚动。浏览范围不得越过资产根。

### SB-3 打开场景

双击场景文件发送一次打开请求，路径使用条目保存的真实路径，而不是从显示名称重新拼接。面板不直接解析文件或清空 World。

未修改时双击即可打开；存在未保存修改时遵循场景控制器的保存/放弃/取消流程。成功后更新当前场景指示；失败显示错误并保留旧场景。加载期间禁止重复激活，并显示忙状态。

面板展示当前打开的场景路径，区分“选中文件”和“当前场景”。单击、滚动和目录导航不改变当前场景。

### SB-4 刷新与失败

首次显示、进入目录、显式 Refresh，以及成功保存到当前目录时更新列表。目录树只按需读取展开分支并缓存；刷新同时失效树与卡片缓存。首版不每帧递归扫描，也不依赖文件监听。对外部文件变化，用户刷新后可见。

目录为空时显示空状态；不存在或不可读时显示可重试错误，不崩溃。当前目录被删除后刷新回到根目录并提示；根目录也不存在时显示错误及重试入口。条目扫描后被删除、改名或变为链接时，激活操作重新验证路径并报告失败。

### SB-5 输入隔离

浏览面板中的点击、双击、滚动、键盘输入不能触发场景拾取或相机移动。保留现有 Escape 光标释放/捕获切换，光标释放时可正常操作浏览器。

viewport 渲染目标大小、拾取原点和缩放因子均来自实际图像区域，不包含浏览面板。布局调整后不允许用旧的完整中央区域尺寸执行拾取。

### SB-6 搜索与卡片

搜索仅在当前目录按名称做不区分大小写的内存过滤，支持清空；不递归搜索，不改场景状态，导航后清空。无匹配项时显示区别于空目录的提示。底部显示筛选后的条目数，支持卡片尺寸调整；窗口变窄后自动换列，长名称截断并通过 hover 提示完整路径。当前场景标记独立于文件选择。Sources 可以隐藏，以在窄面板中保留网格空间。

## Boundaries, errors and compatibility

- 使用与场景加载器相同的场景文件判定和 AssetRoot，不能把所有 RON 都作为场景。
- 文件扫描按当前目录及已展开树节点按需读取并缓存；首次访问、导航和刷新时访问文件系统。显示字符串可做平台适配，真实路径必须保留原始 PathBuf。
- 第一版只有 Folder / Scene 两类条目；数据层的类型区分保留后续扩展点，UI 不预留无效资产操作。
- 初始分割比例与图标属于实现细节，不是场景文件内容。浏览目录、选择条目和面板高度不序列化进场景。

## Acceptance scenarios

### SB-A1 初始布局与导航

启动后在 viewport 下方看到面板，能够调整高度并通过 Reset Layout 恢复。资产目录中包含普通文件夹、空文件夹、嵌套目录和场景文件：目录均可见，双击进入后可返回上级或根目录。

### SB-A2 文件过滤与刷新

目录中同时有 `a.scn.ron`、`B.SCN.RON`、`theme.ron`、模型、图片、临时文件和 `.cache`。只显示普通文件夹及两个场景文件，排序稳定。外部新增场景后 Refresh 可见，删除当前目录后可回到根目录。

### SB-A3 双击统一打开

单击场景文件不加载；双击有效文件只发起一次打开，并在完成后更新 viewport 和当前场景标识。双击损坏或已删除文件显示错误而保留旧场景。未保存修改按 SP-A4 处理。

### SB-A4 输入与尺寸

滚动和双击浏览面板不产生拾取请求、不移动相机。拖动分隔条调整高度后，在 viewport 中点击已知物体仍正确选中，渲染画面不被面板遮挡或按旧尺寸拉伸。

### SB-A5 根目录边界与读取失败

资产根缺失、子目录不可读、条目变为链接及指向根外的链接均不得导致越界浏览或崩溃。错误可见且可以重试；普通无关文件不进入场景打开流程。

### SB-A6 UE 式布局与本地筛选

目录树中单击文件夹使右侧卡片与面包屑同步；从卡片进入嵌套目录时树展开祖先。名称搜索忽略大小写，不显示其他目录的匹配项；清空恢复条目，导航清空搜索。刷新后树与网格均反映新增/删除条目。调整卡片尺寸或收窄窗口后卡片换列且仍可点击；Sources 可隐藏，长名称不越界。保持场景双击打开、未保存保护及输入隔离不变。
