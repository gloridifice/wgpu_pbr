# 场景描述与运行时资产目标契约

## Scope and current contracts

本文是本变更的目标契约，不代表已实现行为。当前没有已批准的同类 current spec；现有 [asset/load.rs](../../../../../../crates/lentille_render/src/asset/load.rs)、[mesh/mod.rs](../../../../../../crates/lentille_render/src/mesh/mod.rs)、[mesh/renderer.rs](../../../../../../crates/lentille_render/src/mesh/renderer.rs) 和 [material/pbr.rs](../../../../../../crates/lentille_render/src/material/pbr.rs) 同时承担来源解析、GPU 准备与实体状态管理。

场景持久化见 [scene-persistence.md](scene-persistence.md)，浏览器只通过 [scene-browser.md](scene-browser.md) 所述入口使用场景能力。

## Requirements

### AR-1 组件分类

序列化组件是可编辑配置的唯一事实来源，允许编辑和行为系统修改；运行时组件由配置与运行环境派生，不参与保存。生成成功不得消耗或删除来源组件。局部 Transform、父引用、网格来源、材质覆盖、相机参数、渲染目标策略、灯光、CSM、环境、测试行为可持久化；世界变换、children 索引、GPU 状态、加载状态、选择状态不可持久化。

删除派生状态后，配置不变且资产有效的实体必须能够再次准备成功，不要求调用原来的场景创建函数。

### AR-2 资产身份和共享

持久资产引用由相对于统一资产根目录的路径及可选子资源选择器组成。glTF mesh、material、image 子资源可引用；其索引依赖源文件内部结构，不保证源文件重排后的身份稳定。

GPU Handle 仅在当前缓存作用域有效，不得写入场景。相同源资产和准备选项在一个场景内共享解析结果和 GPU 数据；不同色彩空间、格式或 mip 策略不能错误命中同一纹理条目。

网格顶点/索引缓冲共享，实例变换 Buffer 和对象 BindGroup 独立。生成器来源必须保存足以重建的参数；不接受只有内存 Handle、没有来源或配方的可保存网格。

### AR-3 材质语义

导入材质为基础，实体只保存覆盖。没有覆盖组件即使用原材质；移除覆盖恢复原材质。每个 primitive 按自己的基础材质合并覆盖，不能以第一个 primitive 替代全部材质。

标量和颜色支持继承或替换；纹理支持继承、替换、清除三种状态。覆盖纹理保存来源，运行时持有已准备的纹理及绑定。只改变 Transform 不得导致共享网格或纹理重新上传。

### AR-4 失效、错误和回收

新增配置、实际配置变化、运行时结果缺失、显式重试均可触发准备。来源或覆盖移除后清理或回退派生状态。失效结果不能作为新配置的 Ready 结果继续绘制。

来源加载失败时保留配置，记录可定位到资产和实体的错误，并允许显式重试或更正引用。不得在每帧无条件重试。运行时缺失或失败的网格跳过绘制，其他就绪实体继续工作。

场景内 CPU/GPU 缓存由场景作用域强持有；切换后释放旧作用域及实体的引用。默认纹理、着色器和公共管线属于应用作用域，不能随场景删除。场景实例与缓存索引不得跨作用域误用。

## Boundaries, errors and compatibility

- CPU 模型解析不得要求 GPU、渲染 World 或创建纹理/Buffer；GPU 准备单独执行。
- 首版同步加载；未来异步加载仍必须防止过期请求覆盖新配置，但本次不实现后台队列。
- 资产路径规范化，拒绝绝对路径、越过资产根目录及通过链接逃逸的路径。不同目录内的同名资产不能碰撞。
- 第一版保留当前 glTF mesh 导入范围，不承诺恢复 glTF node 层级和动画。无效子资源或不支持的数据返回诊断，不静默替换为别的资产。
- 可恢复 IO/解析/资源错误走错误状态；设备丢失等 GPU 致命错误不属于场景事务回滚保证。

## Acceptance scenarios

### AR-A1 共享网格与独立实例

同一场景中两个实体引用同一 mesh，准备后共享一份网格数据。移动一个实体，另一个保持原位；在不更换来源时不再次上传网格。复制实体只复制持久配置，得到新的实例 Buffer。

### AR-A2 重建与来源移除

对已就绪实体删除派生组件，下一次准备恢复正确显示；改换来源后不误画旧网格；移除 MeshSource 后不再绘制该网格。重新添加来源可恢复。

### AR-A3 失败与重试

模型文件不存在时记录一次失败，不因多帧更新反复读取。恢复文件并执行 Retry 后准备成功，保存的原路径始终保留。

### AR-A4 材质与纹理缓存

使用含两种基础材质的 mesh，只覆盖 roughness 后，两部分保留原有颜色和纹理。移除覆盖恢复原材质。纹理清除不等于继承。同一图片按 sRGB 与线性用途加载，不共享错误格式的结果。

### AR-A5 场景作用域释放

从含模型和自定义环境的场景切换到最小场景后，旧场景缓存和实体不再持有旧网格/纹理；窗口与公共管线仍可使用。连续切换不会因遗留场景作用域持续累积资产。
