# 场景文件与生命周期目标契约

## Scope and current contracts

本文描述计划中的保存、加载与替换行为。当前没有场景文件契约，启动内容仍由 [src/lib.rs](../../../../../../src/lib.rs) 创建。资产和组件分类遵循 [asset-runtime.md](asset-runtime.md)。浏览面板是 [scene-browser.md](scene-browser.md) 中的调用方，不拥有场景生命周期。

## Requirements

### SP-1 文件范围

场景文件使用 `.scn.ron` 后缀、UTF-8 文本及显式格式版本。文件保存场景归属实体的组件白名单，不包含全局运行时 Resource、GPU Handle、渲染派生状态和编辑器状态。场景环境、活动相机引用及版本信息由场景根的持久元数据描述。

资产路径相对于资产根目录，而不是场景文件所在文件夹。保存到另一个子目录不改变资产引用含义。持久化是当前可保存配置的快照，不是完整运行过程快照；有意修改局部 Transform 的行为，其当前值会被保存。

### SP-2 身份与层级

由反射场景后端负责文件实体标识到运行时 Entity 的映射，自定义实体引用必须声明映射规则。父节点、活动相机等引用必须指向当前场景内合法实体；拒绝孤立引用、重复标识、父子环和未支持的版本/类型。children 和 WorldTransform 从持久数据重建。

### SP-3 保存

提供 Save、Save As。首次保存未命名场景必须选择资产根内的 `.scn.ron` 路径；另存为已有文件需确认覆盖。新文件父目录必须存在，首版不提供目录创建 UI。

保存先生成完整内容，再写入同目录临时文件并采用目标平台支持的原子替换；不能先截断原文件。替换失败保留旧文件并显示错误。成功后更新当前路径和已保存基线，通知浏览器刷新；失败不清除修改状态。

### SP-4 打开与替换

启动加载、Open、Reload、面板双击使用统一请求入口。打开执行读取、解析、白名单与领域校验、候选资源准备，再提交替换。候选就绪前不加入活动 World，不让单相机/单方向光系统看到半个场景或两个活动场景。

可恢复失败必须保留当前实体、环境、资产作用域及未保存修改。成功后清除旧选择、待处理拾取、属性窗口目标与旧环境状态，安装新场景，再释放旧场景作用域。默认环境也必须设置与之对应的 SH，不得沿用上个场景的数据。

ECS 实体生成完成不等于可渲染；场景 Ready 要求所需 GPU 资产、相机/CSM 和绑定均已准备。失败候选不得改变全局环境 Buffer 或释放当前 viewport 的纹理。

### SP-5 未保存修改与诊断

有实际持久配置修改时标记未保存；仅打开属性面板、重新生成 GPU 数据、更新世界矩阵或调整编辑器布局不得标脏。

打开/重新加载其他内容前，未保存场景提供 Save and Open、Discard and Open、Cancel。保存失败或取消另存为后不继续打开。未修改场景双击即发起打开，无额外确认。

状态至少包含当前场景路径（或未命名）、未保存标志、加载中、失败诊断。错误包含失败文件或资源引用，不能只写日志而不给 UI 反馈。

## Boundaries, errors and compatibility

- 首版保持 Bevy 0.18，反射后端使用该版本 DynamicScene，具体文件封装由 SceneCodec 负责。后续后端升级不应迫使 UI 和资产缓存依赖 Bevy 的序列化类型。
- 第一版只支持一个活动场景、一个活动相机、一个方向光和一个环境；点光源不超过当前 GPU 容量 128。活动相机必须有有效 CSM 配置（级联数 1..=8、正纹理尺寸且不超过设备限制、有效阴影区间）。
- 验证有限数值、有效四元数、正缩放、FOV/近平远平面和灯光参数。当前 TRS 表示不能表达剪切，首版有子节点的变换限制为均匀正缩放；允许叶节点非均匀正缩放。正确应用父旋转/缩放到子位移。
- 不保证 Rust 组件路径/字段重命名后自动读取旧文件；版本不支持时明确拒绝，不静默丢弃数据。
- 正在加载时不接受重复打开动作；UI 显示忙状态。首版同步执行允许短暂停顿，不承诺后台无卡顿加载。
- 场景文件及引用均限制在资产根内；首版不导出到任意系统目录，不跟随符号链接/junction/reparse point。

## Acceptance scenarios

### SP-A1 磁盘往返

创建含父子物体、不同材质覆盖、相机、灯光与环境的场景，修改配置后保存，销毁旧实例并重新打开。配置、关系及显示恢复；文件中没有 GPU/编辑器运行时状态，至少一个源文件内嵌纹理引用也能恢复。

### SP-A2 替换与隔离

从场景 A 切换到 B，世界中只剩 B 的场景实体，窗口和编辑器继续工作；选择与属性窗口不指向 A，B 使用默认环境时不会残留 A 的 SH。B 的活动相机控制器朝向与加载的 Transform 一致。

### SP-A3 拒绝无效输入

损坏 RON、未知类型/版本、场景外引用、父子环、无效参数、丢失模型以及无效 mesh 索引分别给出诊断，旧场景保持可用。加载白名单拒绝运行时组件，即使它已注册 Reflect。

### SP-A4 修改保护与可靠保存

实际修改材质后尝试打开另一场景：Cancel 保留修改；Save and Open 先成功保存再切换；保存失败时留在旧场景。仅展开属性面板不产生未保存提示。文件写入失败不截断已有场景文件。

### SP-A5 无外部模型启动

仓库内提供程序化几何和默认环境的最小场景，在不提供外部模型时可打开；另有迁移后的演示场景。启动和浏览器打开不依赖旧的硬编码场景创建分支。
